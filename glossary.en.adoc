[[glossary]]
== Glossary

[[ala]][[api]][[biodiversity-data-platform]][[clustering]][[community-dna]][[data-vocabulary]][[ddpcr]][[denoising]][[dna-db]][[dna-probe]][[embl]][[ena]][[endpoint]][[ggbn]][[gps]][[hts]][[ingest]][[motu]][[ncbi]][[ngs]][[pipeline]][[qpcr]][[sample]][[seq-align]][[specimen]][[sra]][[tcs]][[zotu]]Short explanations of the terms used in this guide and in the MDT.

[glossary]
[[asv]]Amplicon sequence variant (ASV):: A unique DNA sequence from amplicon sequencing, after sequencing errors have been removed. Treated as a real biological sequence variant. See also <<otu>>.
[[bins]]Barcode Index Number (BIN):: A species-level OTU in <<bold,BOLD>>, made by clustering COI sequences of animals. Each BIN has a unique ID, such as BOLD:ACF1143, which can be used as the scientific name.
[[biom]]BIOM:: A file format for OTU tables with sample and taxonomy information (https://biom-format.org/[biom-format.org]). The MDT reads BIOM 2.1 files and creates BIOM files of your data.
[[bold]]BOLD (Barcode of Life Data System):: A reference database of DNA barcodes, especially COI for animals (https://www.boldsystems.org/[boldsystems.org]). It manages the <<bins,BINs>>.
[[publisher]]Data publisher:: An institution registered with GBIF to publish data. A new publisher must first be approved (endorsed), usually by the <<gbif-node,GBIF node>> of its country.
[[dwc-standard]]Darwin Core (DwC):: The standard GBIF uses for biodiversity data: a set of terms for describing where, when and what was observed (https://dwc.tdwg.org/terms/[term list]).
[[dwc-a]]Darwin Core Archive (DwC-A):: A zip file with the data as tables plus files that describe them and the dataset. It is the format GBIF publishes. The MDT creates it in step 6.
[[dwc-dp]]Darwin Core Data Package (DwC-DP):: A newer Darwin Core format that can hold richer data structures. The MDT also creates one in step 6.
[[dwc-term]]Darwin Core term:: A standard field name, such as term:dwc[decimalLatitude] for latitude.
[[dna-derived]]DNA derived data extension:: A set of terms for DNA information – the sequence, primers, sequencing method and so on – added to occurrence data. Most of its terms come from <<mixs,MIxS>>, so they match the terms used by the <<insdc,INSDC>> archives.
[[doi]]DOI (Digital Object Identifier):: A permanent identifier for a digital object, such as a dataset or a paper. GBIF gives each published dataset a DOI.
[[edna]]Environmental DNA (eDNA):: DNA taken from an environmental sample, such as soil, water or air, without first isolating the organisms.
[[envo]]ENVO (Environment Ontology):: A set of standard terms for environments (https://obofoundry.org/ontology/envo.html[ENVO]). Used in the fields term:mixs[env_broad_scale], term:mixs[env_local_scale] and term:mixs[env_medium].
[[emof]]Extended Measurement Or Facts (eMoF):: A Darwin Core extension for measurements that have no term of their own, such as salinity. See <<map_terms>>.
[[faire]]FAIRe:: A standard for publishing eDNA data (https://fair-edna.github.io/[FAIR eDNA]). The MDT accepts FAIRe files.
[[fastq]]FASTQ:: A text format for raw sequencing reads with quality scores. The MDT does not accept raw reads.
[[gbif]]GBIF (Global Biodiversity Information Facility):: An international network and data infrastructure that gives open access to data about all types of life on Earth.
[[gbif-node]]GBIF node:: A national or organisational member of the GBIF network. Many nodes run their own MDT and approve new data publishers.
[[gbif-taxonomy]]GBIF taxonomy:: The list of names and their classification that GBIF matches the names in every record against. It is the Catalogue of Life Extended Release (https://www.gbif.org/dataset/7ddf754f-d193-4cc9-b351-99906754a03b[COL XR]), which replaced the GBIF Backbone Taxonomy.
[[index]]Indexing:: The processing that GBIF does after publication, so that a dataset's records can be searched, mapped and downloaded on GBIF.org.
[[insdc]]INSDC (International Nucleotide Sequence Database Collaboration):: The public nucleotide archives GenBank, ENA and DDBJ, where raw reads and sample records are deposited.
[[ipt]]IPT (Integrated Publishing Toolkit):: GBIF's free software for publishing datasets (https://www.gbif.org/ipt[gbif.org/ipt]). See <<pub_ipt>>.
[[dna-marker]]Marker:: The DNA region that is amplified and sequenced to identify organisms, such as COI, ITS, 12S or 18S. Also called a barcode region.
[[barcoding]]Metabarcoding:: Amplifying a <<dna-marker,marker>> from a mixed sample by <<pcr,PCR>> and sequencing it, to detect many organisms at once. Also called amplicon sequencing.
[[metagenomics]]Metagenomics:: Sequencing random fragments of all DNA in a sample, without amplifying a marker. The MDT does not handle metagenomic data.
[[mixs]]MIxS (Minimum Information about any (x) Sequence):: Checklists of terms for describing sequence data and samples, from the Genomic Standards Consortium (https://genomicsstandardsconsortium.github.io/mixs/[MIxS]). The <<insdc,INSDC>> archives use them for sample records.
[[obis]]OBIS (Ocean Biodiversity Information System):: A data system for marine biodiversity (https://obis.org/[obis.org]). Datasets published through the MDT can also be shared with OBIS.
[[occurrence]]Occurrence:: An organism at a particular place and time. Each OTU found in a sample becomes one occurrence record.
[[occurrence_core]]Occurrence core:: The main table of a Darwin Core Archive, with one row per occurrence.
[[otu]]Operational taxonomic unit (OTU):: In this guide: any sequence unit in an OTU table, including <<asv,ASVs>> and zOTUs. In the narrow sense, a group of similar DNA sequences treated as one taxon, often clustered at for example 97% similarity.
[[otu-table]]OTU table:: A table with the number of reads of each OTU (rows) in each sample (columns), similar to a species-by-site matrix.
[[pcr]]PCR (polymerase chain reaction):: A method that copies a chosen DNA region many times, using <<primer,primers>>.
[[primer]]Primers:: Short pieces of DNA that bind to both ends of a marker, so that PCR can copy it.
[[sh]]Species hypothesis (SH):: A species-level OTU for fungi in <<unite,UNITE>>. Its ID can be used as the scientific name.
[[test-environment]]Test environment:: A copy of GBIF.org (https://www.gbif-test.org/[gbif-test.org]) for trying out publishing. Nobody uses the data there.
[[unite]]UNITE:: A reference database for the ITS region of fungi and other eukaryotes (https://unite.ut.ee/[unite.ut.ee]). It manages the <<sh,species hypotheses>>.
